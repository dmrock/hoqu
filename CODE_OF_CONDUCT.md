# Code of Conduct

This project is a small, friendly place. The rules are short because they don't need to be
long.

## Expected

- Be decent to people. Assume good faith and ask before assuming malice.
- Keep it in English so everyone can follow along.
- Criticise the code, the design, the decision — not the person who made it.
- Accept that "no" is a complete answer. This is a hobby project; not every idea gets built.

## Not tolerated

- Harassment, insults, or personal attacks, in issues or anywhere else in this repo.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing anyone's private information without permission.
- Sustained disruption: spam, pile-ons, deliberately reopening settled arguments.

## Scope

This applies everywhere the project lives — issues, pull requests, commit comments — and to
anyone participating, including me.

## Enforcement

Email **hello@hoqu.dev**. Reports are read by one person (the maintainer) and kept private.

I'll respond in whatever way seems proportionate: an explanation, a warning, deleting the
content, or blocking the account. I'm not running a tribunal here — if someone is making this
project unpleasant, they'll be removed from it.
